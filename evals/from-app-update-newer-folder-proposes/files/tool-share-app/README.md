# ToolShare

ToolShare lets neighbours lend and borrow tools instead of each buying their own.
We built this prototype with the Riverside Residents' Association over two workshops,
so they could click through the idea before anything is built for real.

## What a resident can do

- Browse the tools neighbours offer, and search them by name or category.
- Offer one of their own tools: name, category, condition and where to pick it up.
- Ask to borrow a tool for a few days. The owner gets an email about the request.
- See their loans, and (as the owner) mark a tool as returned.
- Pay a small deposit before collecting a tool.

## Notes from the workshops

- The association wants loans to stay short so tools keep moving: two weeks at most.
- Nobody may borrow their own tool.
- Messages between neighbours came up a lot. It is only a placeholder for now.
- The deposit screen is for the demo. Nothing is charged.

## Running it

npm install, then npm run dev.
