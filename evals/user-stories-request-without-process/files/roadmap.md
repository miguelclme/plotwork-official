# ToolShare — Roadmap (approved)

**Vision:** let neighbours lend and borrow tools instead of each buying their own.

**Goals**

1. A neighbour can borrow a tool in under five minutes, without phone calls.
2. Fewer tools come back late or damaged.
3. Works for everyone, on any phone.

**Users:** lenders, borrowers, and the neighbourhood coordinator.

**Out of scope:** payments or deposits, delivering tools, insurance.

## Phase 1 — MVP "Borrow a tool"

- Lenders list a tool with a photo, a description and pick-up notes.
- Borrowers search the catalogue by name or category.
- Borrowers request a tool for chosen dates; the lender accepts or declines.
- Both sides see the agreed pick-up and return dates.

## Phase 2 — Trust & returns

- Return reminders: the borrower is reminded the day before the return date, and the lender is told when a return is late.
- Condition check: at hand-back the lender records the tool's condition and can flag damage to the coordinator.

## Phase 3 — Launch readiness

- Pages load in under 2 s on a 4G connection.
- Accessibility audit (WCAG 2.1 AA) before the public launch.
- Usage figures for the coordinator: loans per month and late returns.
